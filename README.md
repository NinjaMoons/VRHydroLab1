# OpenFOAM Labs and Course Project

Учебный workspace с выполненными лабораторными работами ЛР2–ЛР8 и курсовым проектом варианта № 3 по дисциплине «Системы инженерного анализа».

Основные материалы:

- `fast_finish_2026/` — рабочие OpenFOAM cases, scripts и результаты ЛР2–ЛР8;
- `CourseProject_V3/` — параметрическое приложение SALOME + OpenFOAM + ParaView;
- `FINAL_REPORT_LR2.md` … `FINAL_REPORT_LR8.md` — финальные Markdown-отчёты;
- `final_reports/` — подготовленные документы отчётов;
- `screenshots/` — иллюстрации и доказательные изображения;
- `методички/` и `примеры отчетов/` — учебные и справочные материалы.

В репозиторий не включены только кэши, временный QA, дублирующие transfer-пакеты, `processor*` и большие резервные архивы. Исходные cases, последовательные результаты, logs, HDF/UNV, отчёты и код сохранены.

Тяжёлые solver jobs при подготовке репозитория не перезапускались.
