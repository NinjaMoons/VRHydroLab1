## 3:00–7:00 — официальные вопросы ЛР2 и ЛР3

### ЛР2

1. **icoFoam и pisoFoam?** — ламинарный переходный против варианта с турбулентными моделями; в OF13 старые имена совместимы с модульной архитектурой.
2. **mapFields?** — перенос готовых полей на другую сетку/case; `-consistent` при согласованных границах.
3. **2D в OpenFOAM?** — одна ячейка по толщине, торцы `empty`.
4. **Правило сходимости?** — контролировать Co около, но не выше 1; RAS-финал 1,00305 отметить честно.
5. **График?** — `foamPostProcess -func components(U)` и ParaView `Plot Over Line`.

### ЛР3

1. **Решатель многофазного потока и метод?** — `interFoam` в методичке, `incompressibleVoF` в OF13; метод VOF.
2. **Glue Faces?** — склеивает совпадающие геометрические грани для конформной сетки.
3. **Редактирование из терминала?** — в методичке `gedit имя_файла`.
4. **Начальное распределение?** — `system/setFieldsDict`; box/sphere selectors, затем `setFields`.
5. **alpha.water.orig?** — чистый шаблон поля перед новой инициализацией.

## 7:00–11:00 — официальные вопросы ЛР4 и ЛР5

### ЛР4

1. **Высокое Re?** — меньше относительное влияние вязкости, больше отрыв/вихри/неустойчивость.
2. **Линии тока?** — `Stream Tracer`, источник точек, `Apply`.
3. **zeroGradient?** — нулевая нормальная производная; значение идёт из внутренних ячеек.
4. **Ламинарное и турбулентное?** — упорядоченное против пульсационного; наши cases laminar.
5. **noSlip и эквивалент?** — U стенки; для неподвижной `fixedValue uniform (0 0 0)`.

### ЛР5

1. **Конвекция?** — перенос тепла движущейся средой; здесь естественная из-за плотности и g.
2. **Запуск внешних bash-функций?** — Node.js `child_process.spawn/exec`; реально `spawn`.
3. **Ограничение числа временных каталогов?** — `purgeWrite 3`.
4. **Где ideal gas?** — `constant/physicalProperties`.
5. **body-parser?** — разбирает тело HTTP-запроса в Express; реальный проект его не использует.

## 11:00–15:00 — официальные вопросы ЛР6

1. **Если до горла не достигнут звук?** — сверхзвуковая ветвь не возникнет; дозвуковой поток в расширении замедлится.
2. **Расчёт профиля?** — изоэнтропические M/p/T/U/rho → `A=G/(rho U)` → диаметры → длины из углов.
3. **Построение?** — профиль вход–горло–выход → поверхности → extrusion → mesh → группы.
4. **Алгоритмы/hypotheses?** — Segment + Number of Segments → Quadrangle → Hexahedron; 120/80/40/1.
5. **Сгущение SALOME?** — локальная сегментация с прогрессией/начальной и конечной длиной; в нашем скрипте применены фиксированные количества.

## 15:00–19:00 — официальные вопросы ЛР7 и ЛР8

### ЛР7

1. **spawn и exec?** — `exec` буферизует короткий вывод; `spawn` потоковый и лучше для длительных процессов. Реально `spawn`.
2. **Право на выполнение?** — `chmod +x script`.
3. **Начальное распределение?** — `system/setFieldsDict` + `setFields`; в сопле box давления.
4. **Импорт Vue component?** — `import Component from './Component.vue'`; фактический UI без Vue.
5. **Клиент–сервер?** — HTTP/JSON, реальный `fetch`, четыре API route.

### ЛР8

1. **Создание файла для ParaView?** — `touch case.foam` или `paraFoam`.
2. **Case Type?** — Reconstructed / Decomposed; наш последовательный результат reconstructed.
3. **Анимация?** — File → Save Animation; реально 30 PNG → GIF с одной шкалой.
4. **График?** — поля → `Plot Over Line` → две точки/resolution → `Apply` → CSV.
5. **Почему CFD отличается от аналитики?** — 1D стационарная изоэнтропическая модель против 2D переходной дискретной.
