# Лабораторная работа №3

## Цель работы

Построить структурированную гексаэдрическую сетку в SALOME, передать её в OpenFOAM и рассчитать нестационарное движение воды и воздуха методом объёма жидкости VOF.

## Постановка задачи

В двумерной области моделируется обрушение столба воды под действием тяжести. Дополнительно исследуются два начальных распределения воды: центральный параллелепипед и сфера. Свободная поверхность определяется полем объёмной доли `alpha.water`.

## Используемое программное обеспечение

- SALOME 9.16.0: построение геометрии, Hexahedron mesh, группы граней, сохранение HDF и экспорт UNV.
- OpenFOAM Foundation 13: `ideasUnvToFoam`, `transformPoints`, `checkMesh`, `setFields`, `foamRun` с модулем `incompressibleVoF`.
- ParaView 6.1.1: визуализация сетки и `alpha.water`.

## Исходные данные

Фазы: вода и воздух; поверхностное натяжение `sigma=0.07`. Для воды заданы `nu=1e-6 м²/с`, `rho=1000 кг/м³`; для воздуха `nu=1.48e-5 м²/с`, `rho=1 кг/м³`. Вектор тяжести `(0 -9.81 0) м/с²`. Модель переноса импульса — ламинарная.

Базовый столб воды задаётся box-областью `(0 0 -1)`—`(0.1461 0.292 1)`. Вне неё `alpha.water=0`, внутри `alpha.water=1`.

## Расчётная область / геометрия

После масштабирования область имеет размеры 0,584×0,584×0,0146 м и включает нижнюю перегородку. Толщина содержит одну ячейку. Геометрия и сетка сохранены в `fast_finish_2026/LR3/damBreakLaminar/Lab3-final.hdf`, экспорт — `Mesh_1.unv`.

## Граничные условия

В полях используется групповой шаблон `wall`, который применяется к patches типа `wall` (`leftWall`, `rightWall`, `lowerWall`).

| Patch | Поле | Тип | Значение | Физический смысл |
|---|---|---|---|---|
| стены | `U` | `noSlip` | 0 | неподвижные твёрдые стенки |
| стены | `p_rgh` | `fixedFluxPressure` | начальное 0 | согласование давления с потоком у стенки |
| стены | `alpha.water` | `zeroGradient` | градиент 0 | фаза не задаётся извне |
| `atmosphere` | `U` | `pressureInletOutletVelocity` | начальное `(0 0 0)` | открытая граница с учётом направления потока |
| `atmosphere` | `p_rgh` | `prghTotalPressure` | `p0=0` | атмосферное опорное давление |
| `atmosphere` | `alpha.water` | `inletOutlet` | `inletValue=0` | при втекании поступает воздух |
| `frontAndBack` | все поля | constraint `empty` | — | двумерность задачи |

## Настройка расчёта

`controlDict` содержит `solver incompressibleVoF`, `endTime=1`, начальный `deltaT=0.001`, `adjustTimeStep=yes`, `maxCo=1`, `maxAlphaCo=1`, запись через 0,05 с. В `fvSchemes`: Euler, `div(phi,alpha) Gauss interfaceCompression vanLeer 1`, `div(rhoPhi,U) Gauss linearUpwind grad(U)`. В `fvSolution` для `alpha.water` заданы два корректора MULES, а PIMPLE работает с одним внешним и тремя внутренними корректорами.

## Выполнение работы

```bash
ideasUnvToFoam Mesh_1.unv
```

Импортирует сетку и именованные группы SALOME. Журнал подтверждает 4222 точки, 2016 ячеек и все пять patches.

```bash
transformPoints -scale '(0.146 0.146 0.146)'
```

Масштабирует импортированную геометрию до физических размеров; выполнение подтверждено `log.transformPoints`.

```bash
checkMesh -allGeometry -allTopology
```

Проверяет импортированную сетку; результат `Mesh OK`.

```bash
setFields
```

Записывает начальную объёмную долю воды по `system/setFieldsDict`.

```bash
foamRun
```

Читает `solver incompressibleVoF` из `controlDict` и выполняет двухфазный расчёт до 1 с.

Эта же последовательность применена к `centerBox` и `sphere` после изменения только начальной зоны воды.
