# Лабораторная работа --- OpenFOAM + ParaView

## Полная инструкция для Claude Code / Gemini

## Роль

Ты --- инженерный помощник по Linux, CFD и OpenFOAM. Твоя задача ---
провести пользователя через выполнение лабораторной работы полностью: -
установить окружение; - выполнить расчёты; - проверить результаты; -
подготовить отчёт; - объяснить каждый шаг.

Не пропускай этапы. Каждую команду объясняй: - зачем она нужна; - что
изменяет; - какой результат должен появиться.

Если появляется ошибка: 1. Определи причину. 2. Объясни. 3. Дай
исправление. 4. Продолжи выполнение.

------------------------------------------------------------------------

# Цель работы

Изучить рабочий процесс OpenFOAM: - подготовка геометрии; - построение
сетки; - настройка граничных условий; - запуск решателя; - визуализация
результатов в ParaView.

Исследуется задача течения жидкости в квадратной полости cavity.

Геометрия: - квадратная область 0.1 × 0.1 м; - верхняя стенка движется
со скоростью 1 м/с; - остальные стенки неподвижны.

------------------------------------------------------------------------

# Структура OpenFOAM проекта

Каждая задача состоит из каталогов:

0/ - начальные поля: - давление p - скорость U

constant/ - физические параметры: - вязкость - модели

system/ - настройки расчёта: - blockMeshDict - controlDict - fvSchemes -
fvSolution

------------------------------------------------------------------------

# Этап 1. Подготовка задачи cavity

Перейти в рабочую директорию:

``` bash
run
```

Скопировать пример:

``` bash
cp -r $FOAM_TUTORIALS/incompressible/icoFoam/cavity .
```

Перейти:

``` bash
cd cavity
```

------------------------------------------------------------------------

# Этап 2. Создание сетки

Сетка создаётся программой blockMesh.

Файл:

    system/blockMeshDict

Проверить:

-   размеры области;
-   количество ячеек.

Стандартная сетка:

    20 20 1

Для двумерной задачи третье направление равно 1.

Запуск:

``` bash
blockMesh
```

После выполнения проверить отсутствие ошибок.

------------------------------------------------------------------------

# Этап 3. Проверка сетки через ParaView

Запуск:

``` bash
paraFoam &
```

В ParaView:

1.  Нажать Apply.
2.  Включить все Mesh Parts.
3.  Выбрать:

```{=html}
<!-- -->
```
    Surface With Edges

Проверить корректность сетки.

------------------------------------------------------------------------

# Этап 4. Граничные условия

Файл:

    0/p

Настроить давление.

Основные параметры:

dimensions

internalField

boundaryField

Файл:

    0/U

Скорость:

Начальное значение:

    uniform (0 0 0)

Граница движущейся стенки:

    uniform (1 0 0)

Неподвижные стены:

    noSlip

Передняя и задняя грани:

    empty

------------------------------------------------------------------------

# Этап 5. Физические свойства

Файл:

    constant/transportProperties

Для Re=10:

    nu = 0.01

Формула:

Re = dU / nu

где:

d = 0.1 м

U = 1 м/с

------------------------------------------------------------------------

# Этап 6. Настройка расчёта

Файл:

    system/controlDict

Настроить:

startTime:

    0

endTime:

    1

deltaT:

    0.005

writeInterval:

    20

------------------------------------------------------------------------

# Этап 7. Запуск расчёта

Используется решатель:

``` bash
icoFoam
```

В терминале должны появляться:

-   время расчёта;
-   число Куранта;
-   ошибки решения.

Число Куранта должно быть меньше 1.

------------------------------------------------------------------------

# Этап 8. Просмотр результатов

Открыть:

``` bash
paraFoam
```

Обновить времена:

Refresh Times

Выбрать поле:

    p

для давления.

------------------------------------------------------------------------

# Построение давления

В ParaView:

Display:

Representation:

Surface

Coloring:

p

Добавить легенду.

------------------------------------------------------------------------

# Срезы

Создать:

Filters → Slice

Настройки:

Center:

    0.05 0.05 0.005

Normal:

    0 0 1

------------------------------------------------------------------------

# Контуры давления

Filters:

Contour

Contour By:

p

Создать диапазон значений.

------------------------------------------------------------------------

# Векторное поле скорости

Создать:

Filters → Cell Centers

После:

Filters → Glyph

Настройки:

Glyph Type:

Arrow

Orientation:

U

Scale Factor:

0.005

------------------------------------------------------------------------

# Линии тока

Использовать:

Stream Tracer

Seed:

High Resolution Line Source

Точки:

Начало:

    0.05 0 0.005

Конец:

    0.05 0.1 0.005

------------------------------------------------------------------------

# Увеличение сетки

Создать:

cavityFine

Изменить:

blockMeshDict

Было:

    20 20 1

Стало:

    40 40 1

Создать:

``` bash
blockMesh
```

Перенести решение:

``` bash
mapFields -consistent ../cavity
```

------------------------------------------------------------------------

# Сгущение сетки

Использовать grading.

Проверить:

-   размеры ячеек;
-   число Куранта.

------------------------------------------------------------------------

# Увеличение числа Рейнольдса

Создать:

    cavityHighRe

Изменить вязкость:

Запустить:

    icoFoam
