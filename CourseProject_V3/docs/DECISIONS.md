# Технические решения — CourseProject_V3

## D-001. Изоляция проекта

Проект размещён в `CourseProject_V3` и не изменяет `fast_finish_2026/LR7/webapp` или другие лабораторные cases.

## D-002. Единицы

SALOME получает геометрию в миллиметрах. После `ideasUnvToFoam` сетка масштабируется коэффициентом `0.001` в метры. Технологическая толщина фиксирована и равна 1 мм.

## D-003. Сетка

Базовая стратегия — quad-dominant 2D-сетка NETGEN области с отверстиями и её sweep-extrusion на один слой. Это даёт преимущественно гексаэдры с небольшим числом призм, прямо обеспечивает одну ячейку по Z и совместимость `frontAndBack` с типом `empty`. Чисто треугольные попытки были отклонены: расширенный `checkMesh` находил 3–4 призмы с малым determinant. Quad-dominant вариант прошёл `Mesh OK`.

## D-004. Физика baseline

Выбраны вода при приблизительно 20 °C, `nu=1.006e-6 м²/с`, `rho=998.2 кг/м³`, `Uin=0.1 м/с`. Основной режим — incompressible, isothermal, steady SIMPLE, RAS kOmegaSST. Если стационарный расчёт не даст устойчивого инженерного решения, переход к transient PIMPLE допускается только после фиксации причины здесь.

## D-005. Входные турбулентные параметры

Используется инженерная оценка `I=0.16 Re_H^(-1/8)`, длина масштаба `l=0.07H`, `k=1.5(Uin I)^2`, `omega=sqrt(k)/(Cmu^0.25 l)` при `Cmu=0.09`. Значения всегда пересчитываются из текущих `Uin`, `H` и `nu`.

## D-006. Переход от steady к transient

Проверочный steady SIMPLE run завершил 2500 итераций без аварии, но не достиг критериев `1e-5`: начальные residuals продолжили устойчиво колебаться приблизительно на уровнях `U=2–3e-3`, `p=4–5e-3`, `k≈3e-3`, `omega≈1.3e-3`. Такое поведение ожидаемо для вихревых следов семи квадратных препятствий. Поэтому для отчётного baseline используется тот же `incompressibleFluid` case и kOmegaSST, продолженный в transient PIMPLE с адаптивным шагом и `maxCo=0.7`. Стационарный run сохраняется как диагностический, а не объявляется сошедшимся решением.

## D-007. Давление и отчётные экстремумы

Решатель хранит `p` как кинематическое давление в `м²/с²`. Для отчётных значений оно умножается на фактическую плотность `rho=998.2 кг/м³`. Интегральный перепад определяется по areaAverage на inlet/outlet; cell extrema из OpenFOAM и интерполированные point ranges ParaView не смешиваются и сохраняются отдельно в `results/summary.json`.

## D-008. Постобработка

PNG генерируются headless-скриптом ParaView 6.1 из сохранённых полей без повторного CFD. Скрипт формирует пять воспроизводимых видов и JSON с диапазонами данных; каждый полученный кадр визуально проверяется до включения в доказательную базу.
