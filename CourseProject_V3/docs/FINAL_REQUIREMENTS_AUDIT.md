Дата первичного acceptance-аудита: 13 сентября 2026 года.

## Проверенные источники

- исходное ТЗ курсового проекта, вариант №3, разделы 4–7, 25–32;
- методичка `Создание веб-приложения по расчету сопла Лаваля.pdf`, в частности страницы 22, 24, 35, 64 и 77: главная форма, форма результатов, передача исходных данных, состояние выполнения и обработка ошибки;

## Авторитетные пользовательские параметры

| Параметр | Значение и единица | Подтверждённый диапазон backend | Влияние | Необходимые этапы при изменении |
|---|---|---|---|---|
| `L` | 326 мм | 100…1000 мм | Длина канала и координаты квадратов | Геометрия, сетка, OpenFOAM case, solver |
| `H` | 23 мм | 15…200 мм | Высота, уровни рядов, `Re_H`, turbulence length scale | Геометрия, сетка, `k/omega`, solver |
| `a` | 12 мм | 2…50 мм | Сторона квадратов, зазоры, `Re_a` | Геометрия, сетка, solver |
| `P` | 60 мм | 10…250 мм | Шаг центров в каждом ряду | Геометрия, сетка, solver |
| `S` | 30 мм | 1…250 мм | Сдвиг нижнего ряда | Геометрия, сетка, solver |
| `Y` | 8 мм | 1…199 мм | Отступ центров от стенок | Геометрия, сетка, solver |
| `R` | 60 мм | 10…500 мм | Положение последнего верхнего квадрата относительно `outlet` | Геометрия, сетка, solver |
| `Uin` | 0.1 м/с | 0.005…2 м/с | `0/U`, `Re`, `k`, `omega`, расход и решение | OpenFOAM parameterization и solver; геометрия не меняется |
| `quality` | Medium | `Coarse/Medium/Fine` | max/min/local mesh size | Сетка, OpenFOAM case, solver |

Диапазоны — программные защитные пределы текущего backend, а не универсальные физические границы. Дополнительно всегда действуют взаимные геометрические ограничения. `ν=1.006·10⁻⁶ м²/с`, `ρ=998.2 кг/м³`, `kOmegaSST`, quad-dominant режим и толщина 1 мм зафиксированы проектом и не выводятся как обычные пользовательские параметры.

## Текущий фактический pipeline

`UI fields → POST /api/validate → validated settings.json нового run → scripts/geometry.py → salome/generate_mesh.py → HDF/UNV → ideasUnvToFoam → transformPoints → set_patch_types.py → checkMesh → parameterize_case.py → sequential steady SIMPLE → sequential transient PIMPLE → foamPostProcess → pvpython → build_summary.py → summary.json/status/log/images → UI polling`.

Пользовательский ввод не включается в shell-строку: Node.js вызывает Python массивом аргументов, а OpenFOAM-команды заданы внутри фиксированного runner.
