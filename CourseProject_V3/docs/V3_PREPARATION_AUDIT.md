## Подтверждённые параметры и расчётные данные

Вода задаётся кинематической вязкостью `nu = 1.006e-6 м²/с`; плотность `rho = 998.2 кг/м³` используется при переводе кинематического давления в паскали. Расчёт выполнялся последовательно: диагностическая стационарная стадия SIMPLE и нестационарное продолжение PIMPLE. Baseline-сетка содержит 11 364 узла и 5 267 ячеек, из них 5 101 гексаэдр и 166 призм. Расширенная проверка заканчивается сообщением `Mesh OK`.

Для baseline сохранены `max|U| = 0.46627613 м/с`, перепад среднего давления `305.970689626 Па`, `Re_a = 1192.8429`, `Re_H = 2286.2823` и нулевой дисбаланс расхода в точности вывода. Для теста скорости сохранены `max|U| = 0.73750655 м/с` и `Δp = 682.065777722 Па`. Для изменённой геометрии сетка содержит 6 518 ячеек, `max|U| = 0.39990055 м/с`, `Δp = 180.958577198 Па`.

## Итог аудита

Расчётная часть закончена и подтверждена сохранёнными файлами. Для текущего этапа нужны только локальные правки интерфейса, подготовка иллюстраций и новый текстовый пакет для последующей вёрстки в Word. Оснований для повторного CFD-расчёта нет.

## Результат этапа подготовки

После исходного аудита обновлены подписи полей, группировка «Геометрия / Поток / Сетка», динамическая SVG-схема и тексты ошибок. В браузере точечно проверены baseline-загрузка, подсветка `L`, `H`, `a`, `P`, `S`, `Y`, `R`, `Uin`, изменение схемы при допустимом вводе, отказ при `S=5 мм` и загрузка трёх ранее завершённых расчётов. Ошибок JavaScript в консоли не обнаружено; `npm run check` завершился успешно. Полный CFD-расчёт не запускался.
