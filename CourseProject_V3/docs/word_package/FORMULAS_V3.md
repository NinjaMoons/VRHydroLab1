# Формулы для пояснительной записки

## 1. Число Рейнольдса

**Формула:** `Re = U · l / ν`.

**Обозначения:** `U` — характерная скорость потока; `l` — характерный линейный размер; `ν` — кинематическая вязкость.

**Единицы:** `U`, м/с; `l`, м; `ν`, м²/с; `Re` — безразмерная величина.

**Раздел:** 2.2 «Исходные и изменяемые параметры».

В проекте вычисляются два значения: `Re_a = Uin · a / ν` и `Re_H = Uin · H / ν`. Для baseline они равны 1192.84 и 2286.28 соответственно.

## 2. Начальная турбулентная энергия

**Формула:** `k = 3/2 · (Uin · I)²`.

**Обозначения:** `k` — удельная турбулентная кинетическая энергия; `Uin` — скорость на входе; `I` — оценка интенсивности турбулентности.

**Единицы:** `k`, м²/с²; `Uin`, м/с; `I` — безразмерная величина.

**Раздел:** 2.5 «Настройка OpenFOAM».

## 3. Удельная скорость диссипации

**Формула:** `ω = √k / (Cμ^(1/4) · lт)`.

**Обозначения:** `ω` — удельная скорость диссипации; `k` — турбулентная энергия; `Cμ = 0.09`; `lт = 0.07H` — принятая длина турбулентного масштаба.

**Единицы:** `ω`, 1/с; `k`, м²/с²; `lт`, м.

**Раздел:** 2.5 «Настройка OpenFOAM».

## 4. Перевод кинематического давления

**Формула:** `pПа = ρ · p`.

**Обозначения:** `p` — кинематическое давление OpenFOAM; `ρ` — плотность воды; `pПа` — давление в паскалях.

**Единицы:** `p`, м²/с²; `ρ`, кг/м³; `pПа`, Па.

**Раздел:** 2.7 «Результаты в ParaView».
