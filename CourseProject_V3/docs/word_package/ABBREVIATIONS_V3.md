# Список сокращений и обозначений

- **CFD** — вычислительная гидродинамика (Computational Fluid Dynamics).
- **FVM** — метод конечных объёмов (Finite Volume Method).
- **RAS** — осредненные по Рейнольдсу уравнения Навье — Стокса (Reynolds-Averaged Simulation).
- **SIMPLE** — алгоритм связи скорости и давления для стационарного расчёта.
- **PIMPLE** — алгоритм связи скорости и давления для нестационарного расчёта, объединяющий идеи PISO и SIMPLE.
- **HDF** — формат файла исследования SALOME.
- **UNV** — универсальный формат обмена конечно-элементной сеткой.
- **САПР** — система автоматизированного проектирования.
- **Uin** — скорость воды на входе, м/с.
- **ν** — кинематическая вязкость, м²/с.
- **ρ** — плотность, кг/м³.
- **Re** — число Рейнольдса, безразмерная величина.

Обозначения размеров `L`, `H`, `a`, `P`, `S`, `Y`, `R` приведены в основной таблице параметров, чтобы не дублировать её здесь.
